What is NIP-333?

A protocol for distributing Bitcoin block headers over Nostr. Headers are 80-byte cryptographic proofs that enable lightweight clients to verify the Bitcoin blockchain without downloading full blocks.

Quick Start

// Subscribe to Bitcoin headers
["REQ", "headers", {
  "kinds": [33333],
  "#d": ["latest"],
  "#n": ["btc"],
  "limit": 1
}]

Data Sources

The reference implementation provides header archives via GitHub releases:

  • btc.archive.bin — All completed epochs (immutable)
  • btc.current.bin — Current epoch in progress
  • kind:33333 — Latest 12 headers via Nostr
